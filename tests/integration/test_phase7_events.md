## TTS 메시지 (on_message)

### 기본
- [ ] 지정된 TTS 채널에 "안녕하세요" 입력 → 음성 채널에서 한국어 음성 재생
- [ ] 다른 사용자가 입력 → 닉네임은 음성에 포함되지 않고 본문만 읽힘
- [ ] 다른 텍스트 채널에 입력 → **무반응** (정상)

### 전처리 검증
- [ ] `https://example.com 봐` → "링크 봐"로 읽힘
- [ ] `@사용자` 멘션 입력 → 표시명으로 읽힘
- [ ] `**굵게** 안녕` → "굵게 안녕"으로 읽힘
- [ ] 250자 이상 입력 → 200자 정도에서 잘려 읽힘
- [ ] 빈 메시지(첨부만) → 무반응

### 봇/봇간 루프 방지
- [ ] 다른 봇이 TTS 채널에 메시지 입력 → **무반응** (Rule 01 검증)
- [ ] 봇 자기 자신의 응답 메시지 → **무반응**

### 큐 동작
- [ ] 5개 메시지 1초 간격 입력 → 순서대로 끊김 없이 재생
- [ ] 재생 중 새 메시지 → 큐에 쌓여 다음 차례에 재생

## 입/퇴장 (on_voice_state_update)

### 입장
- [ ] 다른 사용자가 음성 채널 입장 → "{닉네임}님 입장" 음성 재생
- [ ] 봇 자기 자신의 입장 이벤트 → **무반응**

### 퇴장
- [ ] 사용자 퇴장 → "{닉네임}님 퇴장" 음성

### 채널 이동
- [ ] 사용자가 다른 음성 채널 → 대상 채널 → "퇴장 → 입장" 둘 다 알림 (또는 정의된 정책)

### 무관 이벤트
- [ ] 같은 채널 내 mute/deafen/screen-share 변경 → **무반응**

## Idle 정책
- [ ] 5분간 메시지 없음 → 봇이 음성 채널 연결 유지
- [ ] 그 후 새 메시지 → 재입장 지연 없이 즉시 재생
