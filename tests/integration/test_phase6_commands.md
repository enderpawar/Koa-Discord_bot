# Phase 6 — Slash Commands Manual Checklist

> 모두 통과해야 Phase 6 완료. 진행자: ____________ / 일시: ____________

## 사전 조건
- [ ] 봇이 테스트 서버에 초대됨
- [ ] `python bot.py`로 봇이 실행 중
- [ ] 콘솔에 `Synced N slash commands` 로그 확인
- [ ] `/읽기채널`, `/음성채널` 이 **명령 목록에 없음** (읽을 채널은 `/입장`이 정한다)

## 명령어 동작

### `/목소리 <종류>`
- [ ] 10개 보이스가 dropdown으로 표시
- [ ] 일반 사용자가 실행 → 권한 부족 안내
- [ ] 선택 시 `config.json`에 `voice` 반영

### `/입장`
- [ ] 사용자가 음성 채널 밖에서 실행하면 "먼저 음성 채널에 입장..." 안내
- [ ] 사용자가 참여 중인 음성 채널에서 실행하면 봇이 같은 채널에 입장
- [ ] `config.json`의 `tts_channel_id`와 `voice_channel_id`가 해당 음성 채널 ID로 함께 반영
- [ ] 해당 음성 채널의 채팅에 메시지 입력 → 별도 채널 설정 없이 TTS 재생

### `/퇴장`
- [ ] 봇이 음성 채널 미입장이면 "음성 채널에 없습니다"
- [ ] 입장 중이면 정상 퇴장

### `/상태`
- [ ] 현재 TTS 채널, 음성 채널, voice가 mention/식별자로 표시됨
- [ ] `발음 사전` 필드에 등록된 규칙 수가 표시됨
- [ ] 미연결 상태에서 실행 → 상태 필드가 `/입장` 을 안내

## 발음 사전 (관리자 대시보드)
- [ ] `/관리자 대시보드` → `발음 사전` 섹션에 `규칙 추가` 버튼이 보임
- [ ] `ㅇㅈ` → `인정` 저장 후 그 음성 채널 채팅에 `그거 ㅇㅈ` 입력 → "그거 인정"으로 읽음
- [ ] 읽을 말을 비운 규칙 → 해당 단어를 소리 내지 않고 건너뜀
- [ ] 규칙 전부 삭제 후 저장 → 원문 그대로 읽음
- [ ] TTS 입력/음성 출력 채널 드롭다운이 대시보드에 **없음**

## 회귀
- [ ] 봇 재시작 후 `config.json`의 설정과 발음 사전이 그대로 유지
