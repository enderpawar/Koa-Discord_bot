코아를 소개합니다

채팅을 듣고, 사람을 모으고, 게임 기록을 한곳에서 확인하는 한국어 Discord 봇입니다.

한국어 음성 10종 지원 여성 5종과 남성 5종 중 서버에 맞는 목소리를 고를 수 있습니다.

코아 봇은?

음성 채널에 모여 있는 동안 채팅 메시지를 자연스러운 한국어 음성으로 읽어 줍니다. 별도의 읽기 채널을 고르지 않아도 현재 음성 채널의 채팅과 바로 연결됩니다.

TTS뿐 아니라 파티 모집, 주간 활동 순위, 오늘의 운세, 롤과 발로란트 전적 조회까지 Discord 안의 흐름을 끊지 않고 이어 줍니다.

문제가 있나요?

봇을 서버에 초대한 뒤 아래 순서만 따르면 바로 TTS를 사용할 수 있습니다.

  1. 1
    음성 채널에 들어가기

    코아가 들어올 음성 채널에 먼저 참여합니다.

  2. 2
    /입장 실행하기

    코아가 현재 음성 채널에 들어오고 TTS를 시작합니다.

  3. 3
    평소처럼 채팅하기

    같은 음성 채널의 채팅을 코아가 순서대로 읽습니다.

버튼으로도 시작할 수 있어요. 음성 채널에 들어갔을 때 표시되는 TTS 모드 버튼을 누르면 /입장과 같은 방식으로 연결됩니다.

음성 읽기

채팅 내용을 정리한 뒤 Azure Speech로 읽습니다. 멘션은 표시명으로, URL은 ‘링크’로 바꾸며 긴 메시지는 적당한 길이에서 자릅니다.

  • 서버별 발음 사전으로 닉네임과 줄임말 교정
  • 오래 밀린 요청을 건너뛰어 대화 지연 방지
  • 일시적인 음성 연결 끊김 자동 복구
  • 마지막 사용자가 나가면 대기열 정리 후 자동 퇴장

파티 모집

제목, 시작 시각, 정원, 메모와 알림 역할을 한 입력 화면에서 작성합니다. 참가자는 버튼으로 참여하고 자리가 차면 자동으로 대기열에 들어갑니다.

참가와 대기

자리가 나면 가장 먼저 기다린 사용자가 자동으로 참가자로 이동합니다.

시작 전 알림

시작 30분 전에 참가자를 부르고 시작 시각에 모집을 자동 마감합니다.

재시작 후 복원

봇이 다시 켜져도 열려 있던 파티 모집을 데이터베이스에서 복원합니다.

활동 순위와 오늘의 운세

자주 묻는 질문

코아가 채팅을 읽지 않아요.

먼저 읽게 할 음성 채널에 들어간 뒤 /입장을 실행해 주세요. 코아가 음성 채널에 들어와 있는지, 메시지를 쓴 곳이 그 음성 채널의 채팅인지 확인하고, 계속 읽지 않으면 서버 설정에서 Koa_Bot 역할의 채널 보기·메시지 보내기·연결·말하기 권한을 확인해 주세요.

슬래시 명령어가 보이지 않아요.

Discord 앱을 완전히 닫았다가 다시 열고, 서버 멤버 목록에 Koa_Bot이 있는지 확인해 주세요. 그래도 보이지 않으면 서버 관리자가 이 페이지의 코아 초대하기 버튼으로 다시 추가해 주세요. 새 명령어가 Discord 전체에 반영되는 데에는 최대 1시간 정도 걸릴 수 있습니다.

발음을 원하는 대로 바꿀 수 있나요?

관리자 대시보드의 발음 사전에 원문과 읽을 말을 등록하세요. 마크다운을 정리한 뒤 사전이 적용됩니다.

빈 음성 채널에도 자동으로 들어오나요?

아니요. 사람이 없는 음성 채널에는 채팅이 올라와도 자동으로 들어가지 않습니다. 사용자가 먼저 참여한 뒤 /입장을 실행해야 합니다.

이제 코아를 시작해 보세요.
