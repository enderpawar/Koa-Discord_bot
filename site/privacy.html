개인정보처리방침

최종 개정일 2026년 8월 17일 · 적용 대상: 디스코드 봇 코아 (Koa)

코아는 채팅 메시지의 내용을 저장하지 않습니다. 읽어 줄 문장은 음성으로 합성하는 순간에만 사용되고, 합성된 음성 파일은 재생 직후 삭제됩니다. 또한 코아는 음성 채널에서 소리를 내보내기만 하며, 마이크 입력을 수신하거나 녹음하지 않습니다.

1. 저장하는 정보

코아는 기능 동작에 필요한 최소한의 정보만 저장합니다. 모든 데이터는 디스코드 서버 단위(guild_id)로 격리되며, 다른 서버의 데이터와 섞이지 않습니다.

항목 목적 보관 기간
서버 ID, 채널 ID 읽을 채널·음성 채널 연결, 리더보드 발송 채널 지정 설정이 변경되거나 삭제될 때까지
서버 설정 (선택한 목소리, 발음 사전, 리더보드 발송 시각, 파티 티어 뱃지 사용 여부) 서버별 봇 동작 유지 설정이 변경되거나 삭제될 때까지
사용자 ID, 음성 채널 체류 시간(초), 메시지 개수 주간 활동 점수와 순위 산출. 메시지 내용은 저장하지 않고 개수만 셉니다. 매주 금요일 00:00 (KST) 초기화
파티 모집 정보 (제목, 메모, 정원, 시작·만료 시각, 모집자 및 참가자·대기자 사용자 ID, 메시지 ID) 모집 상태 유지, 시작 전 알림, 재시작 후 복원 시작 시각으로부터 7일 후 자동 삭제
라이엇 ID (게임 닉네임, 태그, 지역) 전적·랭크 조회, 파티 티어 뱃지 표시 사용자가 등록을 해제할 때까지
게임 티어 조회 결과 (게임, 티어, 단계, PUUID) 동일 조회 반복 방지를 위한 캐시 24시간 후 만료
관리자 대시보드 일회용 링크의 해시값, 발급 대상 서버·사용자 ID, 발급·만료 시각 관리자 본인 확인. 링크 원문은 저장하지 않습니다. 발급 후 5분 또는 1회 사용 시 폐기

2. 저장하지 않는 정보

  • 채팅 메시지의 내용 — 디스크에 저장하지 않으며, 로그로도 남기지 않습니다.
  • 음성 채널의 소리 — 코아는 음성을 송출만 합니다. 음성 수신·녹음 기능이 코드에 존재하지 않습니다.
  • 합성된 음성 파일 — 임시 파일로 만들어 재생한 뒤 곧바로 삭제합니다.
  • 이메일 주소, 전화번호, 실명, 주소 등 디스코드 계정 외의 개인 식별 정보.
  • 결제 정보 — 코아는 유료 기능이나 결제 수단을 제공하지 않습니다.

3. 제3자 서비스로 전송되는 정보

일부 기능은 외부 서비스를 사용합니다. 아래 정보는 해당 기능을 사용하는 순간에만 전송되며, 각 서비스의 처리 방침이 함께 적용됩니다.

서비스 전송되는 정보 시점
Microsoft Azure Speech (개인정보처리방침) 읽어 줄 문장의 텍스트와 선택된 목소리 이름. 사용자 ID나 서버 정보는 함께 보내지 않습니다. TTS가 켜진 채널에 메시지가 올라올 때
Riot Games API (개인정보처리방침) 등록된 라이엇 ID와 PUUID 리그 오브 레전드 전적·랭크를 조회할 때
HenrikDev API (발로란트 조회 중계) 등록된 라이엇 ID 발로란트 전적·티어를 조회할 때
YouTube 사용자가 입력한 영상 주소 음악 기능이 활성화된 서버에서 재생을 요청할 때 (기본값은 비활성)

코아는 어떤 정보도 광고 목적으로 사용하거나 제3자에게 판매하지 않습니다. 수집한 정보로 사용자 프로필을 만들거나 서버 간 활동을 연결하지 않습니다.

4. 삭제 요청

사용자가 직접 삭제할 수 있는 것

  • 라이엇 ID 등록 — /롤 등록해제 또는 /발로란트 등록해제를 실행하면 즉시 삭제됩니다. 티어 뱃지도 함께 사라집니다.
  • 내가 연 파티 모집 — /파티취소로 삭제할 수 있습니다.

서버 관리자가 삭제할 수 있는 것

  • 활동 순위 데이터 — /관리자 대시보드의 리더보드 데이터 초기화로 서버 전체 기록을 지울 수 있습니다.
  • 발음 사전 — 같은 대시보드에서 개별 규칙을 삭제할 수 있습니다.

봇을 서버에서 내보낸 경우

코아를 서버에서 내보내면 해당 서버의 파티 모집 데이터와 티어 캐시는 자동으로 삭제되고, 발급된 관리자 링크와 세션은 즉시 폐기됩니다.

다만 서버 설정, 활동 순위 기록, 라이엇 ID 등록 정보는 자동으로 삭제되지 않습니다. 이는 봇을 실수로 내보냈다가 다시 초대했을 때 설정을 복구하기 위한 것입니다. 완전한 삭제를 원하시면 아래 연락처로 서버 ID를 알려 주시면 처리해 드립니다.

5. 데이터 보관 장소와 보호

  • 데이터는 운영자가 관리하는 단일 서버 인스턴스에 저장되며, 외부에 공개된 데이터베이스 포트를 두지 않습니다.
  • 관리자 대시보드는 고정 비밀번호나 마스터 토큰을 사용하지 않습니다. 디스코드가 관리자 권한을 확인한 뒤 발급하는 5분·1회용 링크로만 접근할 수 있고, 링크는 해시 형태로만 저장됩니다.
  • 대시보드 세션은 유휴 15분 또는 최대 30분에 만료되며, 모든 요청마다 디스코드 관리자 권한을 다시 확인합니다.
  • 대시보드 공개 주소는 HTTPS로만 제공됩니다.

6. 만 13세 미만 이용자

코아는 디스코드 이용약관을 따르며, 디스코드가 정한 최소 연령(지역에 따라 만 13세 이상) 미만의 이용자를 대상으로 하지 않습니다. 해당 이용자의 정보가 저장된 것을 확인하면 삭제합니다.

English summary

Koa is a Korean-language Discord bot. It does not store message content — text is sent to Microsoft Azure Speech only at the moment of synthesis, and the resulting audio file is deleted immediately after playback. Koa only transmits audio and never receives or records voice input. It stores, isolated per guild: channel and guild IDs, per-guild settings (voice, pronunciation dictionary, leaderboard schedule), voice minutes and message counts for weekly rankings (reset every Friday 00:00 KST), party recruitment records (auto-deleted 7 days after start time), Riot IDs registered by users (deletable at any time via /롤 등록해제), a 24-hour game tier cache, and hashes only of single-use admin dashboard links (valid 5 minutes, one use). No data is sold, used for advertising, or linked across servers. Third-party recipients are Microsoft Azure Speech, Riot Games API, HenrikDev API, and YouTube (music is disabled by default). Removing the bot from a server deletes that server's party data and tier cache and revokes all admin links immediately; settings, rankings, and Riot ID registrations are retained so they can be restored on re-invite, and are deleted on request.
